# Real Language Learner

Первый MVP приложения для тренировки немецкого и греческого по реальным субтитрам.

## Запуск через Docker

```powershell
docker compose up --build
```

Создай рядом с проектом папку `media`, внутри неё папки языков, и положи видео и
субтитры с одинаковым именем:

```text
media/
  de/
    episode-01.mp4
    episode-01.xml
  el/
    episode-01.mp4
    episode-01.xml
```

Поддерживаются SRT и TTML/XML (включая формат EBU-TT-D-Basic из потокового видео).
Язык определяется выбранной папкой, а не именем файла. После запуска открой
http://localhost:8000, выбери язык и нажми «Просканировать папку языка».

В Windows приложение можно запустить двойным щелчком по файлу
`Запустить Real Language Learner.bat`. Скрипт проверит Docker Desktop, соберёт и
запустит контейнер, дождётся ответа сервера и откроет приложение в браузере.
Если Docker Desktop не запущен, скрипт попробует запустить его самостоятельно.
Команды Docker выполняются без вывода. Для полностью скрытого запуска можно
использовать `Запустить Real Language Learner скрыто.vbs`; Docker Desktop при
этом всё равно может показать собственное окно, так как это графическое
приложение.
Для остановки используйте `Остановить Real Language Learner.bat`.

На главной странице есть поиск по теме. Кнопка «Адаптировать к поиску»
преобразует описание темы в леммы и устойчивые выражения через выбранный LLM-провайдер.
Список можно отредактировать вручную, после чего поиск находит подходящие
фразы среди импортированных субтитров. Для адаптации добавьте `LLM_TOKEN` в
`.env`; модель и URL можно изменить через `LLM_MODEL` и `LLM_API_URL`.
Если бесплатная модель временно перегружена, можно указать через запятую
резервные модели в `LLM_FALLBACK_MODELS`.

Текущий MVP хранит фразы и историю в SQLite volume, а видео остаются в папке `media`.
В браузере видео открывается по таймкоду фразы. Для воспроизведения лучше использовать
MP4 с H.264/AAC или WebM: не каждый браузер воспроизводит MKV напрямую.
Описания звуков и музыки, заключённые в `*...*` или `[...]`, автоматически исключаются
из упражнений.

На главной странице можно настроить тренировку: отдельно указать количество заданий
на аудирование и перевод, а для аудирования выбрать короткие, средние или длинные
фразы. Средний режим ограничен 9 секундами, короткий — 4,5 секундами, длинный —
15 секундами. После настройки открывается отдельная страница тренировки.

Переводы запрашиваются лениво при первом появлении фразы и сохраняются в SQLite.
Для перевода используется бесплатный MyMemory API без API-ключа:

```text
TRANSLATION_URL=https://api.mymemory.translated.net/get
```

Ограничение бесплатного API — до 500 UTF-8 байт на одну фразу. После этого запускай
обычной командой:

```powershell
docker compose up --build
```

В переводных заданиях русский ответ собирается из слов-кнопок; среди них есть
дополнительные слова. Оригинальные субтитры скрыты до нажатия кнопки-подсказки.
Видео переводного фрагмента можно повторить или замедлить, а воспроизведение
получает небольшой запас до и после таймкода, чтобы не обрезать начало или конец
реплики.

Доступен отдельный раздел «Словарь». Выделенное слово из показанного оригинала
можно добавить в словарь, перевод создаётся автоматически и редактируется вручную.
Слова хранятся отдельно для немецкого и греческого языков; галочка участия в
тренировке сохраняется. В словарной тренировке можно задать количество вопросов
в обоих направлениях, а ошибочные слова повторяются в конце. Такая тренировка
сохраняется в истории одной записью.

На странице настройки обычной тренировки показывается примерная длительность
аудирования, перевода и всей тренировки. Расчёт использует последние десять
завершённых упражнений соответствующего типа; если истории ещё нет, используются
базовые оценки. В самой тренировке отображается номер текущего задания, а для
ошибочных заданий — отдельная пометка закрепления.

Новые задания аудирования и перевода перемешиваются в общей очереди. На странице
настройки можно задать количество заданий напрямую либо выбрать длительность
тренировки и долю времени на аудирование с помощью ползунка; количество заданий
пересчитывается автоматически.

Во всех разделах доступен выбор темы: обычная, сдержанная светлая, тёмная и
креативная. Выбор сохраняется в браузере.

В истории доступен отдельный режим «Закрепление из истории». Можно выбрать язык,
окно последних неудачных попыток (10, 20, 30, 50, 75, 100 или вся история) и
количество случайных упражнений. Каждое выбранное упражнение повторяется до
правильного ответа.

Файл `.env` не нужно публиковать или коммитить; шаблон находится в `.env.example`.

На странице «История заданий» отображаются дата последней попытки, материал,
таймкод, текст фразы и тип упражнения. Нажатие на строку открывает отдельную
отработку этого задания; для аудирования она остаётся открытой до правильного
ответа. В основной тренировке задания с ошибками возвращаются в конце и
повторяются до успешной попытки.
